      Albums

      Pick a previously scanned album or choose a new folder from disk.

        Scan Photo Folder

        Ingest reads EXIF and clusters photos locally. No photos leave your Mac and nothing is modified.

        Propose Locations

        Sends 1280 px JPEG previews to the selected vision provider and geocodes guessed place names. Never writes to photo files.

        Vision provider

        Gemini has no per-request store=false. Free-tier keys may be used to improve Google products — use a billing-enabled key for real photos.

        Write GPS to Accepted Photos

        In-place writes mutate original files directly. You can revert them afterward with Undo.

        Undo Written GPS Tags

        Restores pre-write backups for JPEG/HEIC/PNG and removes/restores RAW .xmp sidecars, preserving any file modified after write.
